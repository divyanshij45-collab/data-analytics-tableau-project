Project Overview

This project uses Tableau to explore how fuel prices and taxation policies differ across countries, regions, income groups, and subsidy levels.

Project Objective

Understand global fuel-price variation and examine how taxes and subsidies relate to petrol and diesel prices.

Key Indicators

Petrol prices, diesel prices, average tax percentage, subsidy levels, regional volatility, and Brent crude trends.

Use the Tableau dashboards to compare countries and groups, apply filters, and explore patterns in the data.
